# TiO2 Photocatalysis ML Dataset 🧪🤖

A curated, **machine-learning ready dataset** of **TiO2-based photocatalytic degradation experiments** extracted from peer-reviewed scientific literature.

## 📊 Dataset Overview

- **Total experiments:** 47 high-confidence observations
- **Features:** 23 experimental descriptors
- **Target:** Pollutant removal/degradation percentage
- **Domain:** Environmental photocatalysis, materials science, water treatment

### Key Variables
- **Catalysts:** TiO2 variants, doped materials, composites, biomass-supported photocatalysts
- **Pollutants:** Organic dyes, pharmaceuticals, phenolic compounds, wastewater
- **Light sources:** UV, Visible, Solar, Sunlight
- **Experimental conditions:** pH, temperature, time, catalyst dosage, concentration

## 🎯 Use Cases

- Predict degradation efficiency from experimental conditions
- Optimize photocatalyst selection
- Meta-analysis of TiO2 photocatalysis literature
- Transfer learning for related catalytic systems
- Educational resource for materials informatics

## 📁 Dataset Files

| File | Description | Shape |
|------|-------------|-------|
